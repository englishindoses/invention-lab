How to Play

The teacher controls the game and shares the screen. The student invents and speaks; the teacher plays the customer.

  1. Enter the lab. First time: use Register Inventor, then enter the same name and password in Lab Access. Returning inventors use Lab Access.
  2. Pull both levers. Each pull costs 1 inventor coin. Reroll either word to change only that word.
  3. Invent and explain. Combine the two words into an invention and persuade the teacher to buy it.
  4. Name and sell. Type the invention name. With both words and a name ready, choose Buy 10, 50, 100, or Don't Buy. The result saves automatically and clears the machine for the next round.

Inventors start with 20 coins. At zero, Free Restart Bonus adds 10. Buy for 10, 50 or 100 coins. The customer's wallet starts at 300 per lesson; use the gear next to the wallet balance to adjust it. Changing the limit keeps coins already spent; purchases transfer coins to the inventor. Leave Lab and sign in again to start a fresh customer budget.

My Inventions shows completed rounds. Achievements and Statistics track progress. The settings gear changes theme and sound. In Shop, use Add Item to upload a picture; click an item to edit or remove it.

Progress stays in this browser on this device. Statistics → Export backup saves notebooks (export only). Shop → Export Shop saves pictures and shelves; Import Shop replaces the current inventor's shop. Keep backups before clearing browser data.
